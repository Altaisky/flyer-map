# История проекта: Map

Сжатый журнал значимых изменений. Новые записи сверху.

## 2026-05-22
- Добавлен статус «Закомментировано» (фиолетовый): авто-сохранение дома с комментарием при закрытии попапа
- Реализована система комментариев: кнопка 💬 в попапе, золотая точка-индикатор на маркере, prompt для ввода
- Исправлен баг: комментарий терялся из-за вызова removeTempMarker до копирования tempComment
- Убран статус «Готов снова» (expired): по истечении таймера дом переходит в «Обклеить»
- Убран статус «Новый» (pending): клик по карте показывает временный маркер с выбором, закрытие без выбора — дом не создаётся
- Исправлена цветовая схема: active=зелёный (соответствует кнопке «Обклеено»), planned=оранжевый («Обклеить»)
- Сайдбар: гамбургер перенесён в нижний левый угол, кнопка закрытия туда же, зум в нижний правый
- Убран кнопка «Навигация» из попапа, убраны пресет-кнопки периода паузы
- Исправлена коррупция index.html (литерал `...` вставлялся как текст при использовании в edit)

## 2026-05-19
- Добавлена геолокация: кнопка ⌖ — центрирует, показывает синюю точку, отслеживает
- Добавлен обратный геокодинг через Nominatim: адрес (улица, номер дома) в попапе
- Кнопка закрытия попапа увеличена до 40×40px глобально
- PWA с автообновлением SW: network-first для HTML, cache-first для CDN
- Приложение развёрнуто на GitHub Pages: https://altaisky.github.io/flyer-map/
- Мобильная версия: полноэкранная карта, сайдбар-ящик, тач-оптимизация
- Система статусов: плановая (Обклеить), активная (Обклеено, таймер), исключено
- Создан проект: HTML+CSS+JS + Leaflet + OpenStreetMap
