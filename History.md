# История проекта: Map

Сжатый журнал значимых изменений. Новые записи сверху.

## 2026-06-03
- Геолокация: авто-фолбэк с GPS на Wi-Fi/вышки (жёлтая кнопка + toast-уведомление)
- Точка навигации в отдельном слое locationPane (z-index 650), всегда поверх меток
- Карта не сбрасывает позицию при отслеживании — центрируется только один раз
- Поиск любого адреса через Nominatim (прямой геокодинг), с фолбэком на отмеченные дома
- Список домов: оверлей с сортировкой (адрес/дата/статус), фильтрацией, клик переходит к дому
- Фильтры: цветные кнопки (сплошной фон + белый текст), opacity для неактивных
- Кастомный диалог комментариев (автофокус, autocapitalize, Enter для сохранения)
- После сохранения комментария попап закрывается автоматически
- Убрано подтверждение при удалении дома
- Поворот карты (rotate) — добавлен и откачен, несовместим с user-scalable=no

## 2026-05-22
- Офлайн-кэширование тайлов: кнопка «Сохранить область», отдельный кэш SW, единый поддомен tile.openstreetmap.org
- Статус «Закомментировано» (фиолетовый): авто-сохранение дома с комментарием при закрытии попапа
- Кнопки попапа: «Обклеено» доступно из Исключён, «Обклеить» доступно из Обклеено
- Фильтр «Закомментировано» показывает все дома с комментариями
- Убран статус «Готов снова» (expired): по истечении таймера дом переходит в «Обклеить»
- Убран статус «Новый» (pending): временный маркер с выбором, закрытие без выбора — дом не создаётся
- Исправлена цветовая схема: active=зелёный, planned=оранжевый

## 2026-05-19
- Геолокация + обратный геокодинг через Nominatim
- PWA с автообновлением SW на GitHub Pages
- Мобильная версия: полноэкранная карта, сайдбар-ящик, тач-оптимизация
- Создан проект: HTML+CSS+JS + Leaflet + OpenStreetMap
