# История проекта: Map

Сжатый журнал значимых изменений. Новые записи сверху.

## 2026-05-19
- Приложение превращено в PWA: добавлены manifest.json, service worker (офлайн-кэш), иконки 192/512px
- Развёрнуто на GitHub Pages: https://altaisky.github.io/flyer-map/
- Добавлена мобильная версия: полноэкранная карта, сайдбар как выдвижной ящик (гамбургер-кнопка), увеличенные маркеры (32px) и тач-кнопки попапа, `100dvh` для высоты
- Переработана система статусов: вместо 3 (ожидает/на паузе/готов) стало 5 — новый, обклеить (план), обклеено (таймер), готов снова, исключён
- Добавлены действия в попап: «Обклеить» (план), «Обклеено» (запускает таймер), «Исключить», «Удалить»
- Создан проект: HTML+CSS+JS приложение с Leaflet + OpenStreetMap для отслеживания расклейки объявлений
- Исправлен баг: клик по кнопкам popup создавал дублирующий маркер — добавлен флаг `blockMapClick` с авто-сбросом по таймауту
