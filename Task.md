# Задача проекта: Map

_Обновлено: 2026-06-03_

## Цель
PWA-приложение для отслеживания расклейки объявлений на подъездах домов в конкретном районе города. Пользователь отмечает на карте дома, фиксирует дату обклейки, оставляет комментарии и видит, когда можно повторно клеить объявления. Работает офлайн на телефоне.

## Scope MVP
- Интерактивная карта реального города (OpenStreetMap + Leaflet)
- Клик по карте → карточка выбора статуса (без создания при закрытии)
- 4 статуса: Обклеить (оранжевый), Обклеено (зелёный, таймер), Исключён (серый), Закомментировано (фиолетовый)
- Комментарии к домам с визуальным индикатором (золотая точка) и кастомным диалогом ввода
- Настраиваемый период паузы (по умолчанию 30 дней)
- Фильтрация маркеров по статусу (цветные кнопки)
- Список домов с сортировкой (по адресу, дате, статусу) и фильтрацией
- Поиск любого адреса через Nominatim (не только отмеченные дома)
- Сохранение данных в localStorage, экспорт/импорт JSON
- Тёмная тема, адаптив (десктоп + мобильная версия)
- PWA: установка на телефон, офлайн-кэш, автообновление
- Офлайн-кэширование тайлов карты (сохранение области)
- Геолокация: GPS + авто-фолбэк на Wi-Fi/вышки сотовой связи
- Обратный геокодинг (адрес по координатам через Nominatim)

## Вне scope
- Авторизация пользователей
- Бэкенд / серверное хранение данных
- Нативное мобильное приложение
- Мультипользовательский режим
- Поворот карты (rotate/touchRotate) — добавлен и откатан, не работает стабильно

## Функциональные требования
- Карта открывается на последней просмотренной позиции
- Клик по карте показывает временный маркер с выбором: Обклеить / Обклеено / Исключить / 💬
- Закрытие карточки без выбора — дом не создаётся
- При наличии комментария и закрытии карточки — дом сохраняется как «Закомментировано»
- Комментарий вводится в кастомном диалоге (автофокус, autocapitalize)
- «Обклеено» запускает таймер кд; по истечении дом переходит в «Обклеить»
- Геолокация: сначала GPS, при неудаче — автоматически Wi-Fi/вышки (жёлтая кнопка + уведомление)
- При выключенной геолокации — поле поиска любого адреса
- Кнопка «Сохранить область офлайн» кэширует тайлы текущего вьюпорта

## Критерии приёмки
- Можно добавить дом кликом по карте, выбрать статус
- После «Обклеено» маркер зелёный, видно оставшееся время
- После истечения кд маркер оранжевый, доступно повторное «Обклеено»
- Комментарий виден в попапе, золотая точка на маркере
- Данные сохраняются между сессиями
- PWA устанавливается на телефон, работает офлайн
- Сохранённые тайлы видны без интернета
