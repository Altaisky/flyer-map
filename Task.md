# Задача проекта: Map

_Обновлено: 2026-05-19_

## Цель
Веб-приложение для отслеживания расклейки объявлений на подъездах домов в конкретном районе города. Пользователь отмечает на карте дома, фиксирует дату обклейки и видит, когда можно повторно клеить объявления.

## Scope MVP
- Интерактивная карта реального города (OpenStreetMap + Leaflet)
- Добавление маркеров домов кликом по карте
- Три статуса дома: ожидает (синий), на паузе/кд (красный), готов снова (зелёный)
- Настраиваемый период паузы (по умолчанию 30 дней)
- Фильтрация маркеров по статусу
- Сохранение данных в localStorage
- Экспорт/импорт данных в JSON
- Тёмная тема интерфейса

## Вне scope
- Авторизация пользователей
- Бэкенд / серверное хранение данных
- Мобильное нативное приложение
- Поиск по адресу / геокодинг
- Мультипользовательский режим

## Функциональные требования
- Карта открывается на последней просмотренной позиции
- Клик по карте создаёт маркер нового дома со статусом «ожидает»
- Клик по маркеру показывает popup с информацией и кнопками действий
- Кнопка «Обклеить» переводит дом в статус «на паузе», запускает таймер
- Кнопка «Сбросить» сбрасывает дом в статус «ожидает»
- Кнопка «Удалить» убирает дом с карты
- По истечении периода паузы дом автоматически переходит в «готов снова»
- Статистика в сайдбаре обновляется в реальном времени

## Критерии приёмки
- Можно добавить дом кликом по карте и увидеть синий маркер
- После нажатия «Обклеить» маркер краснеет, показывается оставшееся время
- После истечения кд маркер зеленеет, кнопка «Обклеить» снова доступна
- Данные сохраняются между сессиями (localStorage)
- Экспортированный файл можно импортировать на другом устройстве
